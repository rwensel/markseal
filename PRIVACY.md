# Privacy

MarkSeal runs entirely on your machine. It does not collect telemetry, analytics, or usage data, and it does not upload screenshots or their contents.

The only network access is the optional update check. It is off by default. When enabled, it fetches a small public release manifest and, if an update exists, the installer; it exchanges release metadata (version, notes, download URL, SHA-256) and never image data. No account is required.

The application reads and writes only the images you open, the files you export, and its local settings and performance logs. Nothing is sent to the maintainer.
